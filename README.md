
Project Overview

Tech Academy is a web-based application developed to manage and showcase an  training institute. The application allows users to view available courses and placement details, register for demo classes, and submit enquiries. An admin panel is provided to manage student, staff, and enquiry details efficiently.

This project demonstrates full-stack development skills using frontend technologies, Java backend, and MySQL database integration.
